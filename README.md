# 小D 桌宠（xiaod-pet）

一个住在桌面上的像素小恐龙。它盯着 **Reasonix Studio** 的会话状态：
你在干活时它就坐在旁边敲键盘，头顶的云朵显示它以为你在做什么。
**拖文件到它身上**还能就地转格式（图片 / 音视频 / Word / PPT / Excel）。

| 项 | 值 |
| --- | --- |
| 版本 | 1.0.0 |
| 许可 | MIT（见 `LICENSE`） |
| 维护人 | 弱志 |

## 安装

```
reasonix plugin install <本目录> --yes
```

装完**重启 Studio 或新开一个会话**（hooks 不热加载）。

卸载：

```
reasonix plugin remove xiaod-pet --yes
```

## 依赖

插件声明了 7 个 hook，RS 会调用 `hooks/notify.py`。
**`notify.py` 本身只用 Python 标准库**，所以任何 Python 都能跑它。

真正需要第三方库的是桌宠本体 `bin/pet.py`。`notify.py` 会自动在候选
解释器里找**装了 Pillow 的那个**（依次探测 `XIAOD_PYTHON` 环境变量 →
当前解释器同目录 → 常见安装路径 → PATH 上的启动器），并缓存结果。
想手动指定：

```
set XIAOD_PYTHON=C:\path\to\pythonw.exe
```

### 必需

| 依赖 | 用途 | 缺失后果 |
| --- | --- | --- |
| **Python 3.10+** | 运行环境 | 跑不起来 |
| **Pillow** | 渲染像素形象、云朵 | **跑不起来**（顶层 import） |
| **tkinter** | 窗口 | **跑不起来**（Python 官方安装器默认自带） |

### 可选（缺了自动降级，不影响本体）

| 依赖 | 用途 | 缺失后果 |
| --- | --- | --- |
| **pywin32** | 全屏自动隐藏 | 全屏时不再自动收起 |
| **psutil** | 检测 RS 是否在跑 | 不再随 RS 退出而退出 |
| **pystray** | 托盘图标 | 没有托盘菜单（右键菜单仍在） |
| **openpyxl** + **python-docx** | Excel → Word / csv | 该转换不可用 |
| **win32com** + **Microsoft Office** | Word/PPT/Excel → PDF | 该转换不可用（**原版渲染，需本机装 Office**） |
| **ffmpeg** | 音视频互转 | 该转换不可用（自动在 PATH 与 WinGet 目录找） |

一次性装齐：

```
pip install Pillow pywin32 psutil pystray openpyxl python-docx
```

> 转 PDF 走 **COM 调用本机 Office**，是原版渲染（排版/字体/图表全对），
> 代价是每次 5~8 秒。没装 Office 就用不了这类转换，其它功能不受影响。

## 最小可用示例

**输入**：在 Reasonix Studio 里随便发一句话给模型。

**预期结果**：
1. 小D 出现在桌面（首次由 hook 自动拉起）
2. 头顶云朵显示 **「正在思考…」**
3. 它**坐在一台小笔记本电脑前**，眼睛左右转动、不敲键盘
4. 一旦开始改文件，云朵变 **「正在写入…」**，动作换成**敲键盘**（屏幕发光）
5. 一轮结束，云朵显示 **「搞定了！」**，它蹦跳欢呼

**验证它真的在跑**：

```
curl http://127.0.0.1:31726/status -d "{}"
```

端口有响应即正常（返回内容不重要）。

## 一个已知的失败用例

**输入**：把一段**没有音轨**的视频（例如无声录屏）拖到小D 身上，选「转成 MP3」。

**表现**：云朵显示 **「这个文件里没有声音，没法转成音频」**，不产出文件。

**这是预期行为，不是崩溃**。底层 ffmpeg 在这种情况下只会报一句
`Error opening output files: Invalid argument`，完全看不出原因；
插件在转换前先探测音轨，换成了一句人能看懂的话。

## 隐私

**hook 只转发事件名和工具类别**，不读也不转发：

- 你的提示词
- 工具参数（文件路径、命令内容）
- 工具输出、文件内容

`notify.py` 永远 `exit 0`，所以**不会阻断任何工具调用**。它也可以随时
删掉——删了插件只是不再有状态提示，RS 本身不受任何影响。

## 它有哪些行为

| 你在干什么 | 云朵显示 | 小D 的动作 |
| --- | --- | --- |
| 发消息 / 构思 | 正在思考… / 正在构思… | 坐在电脑前，眼睛转 |
| 改文件 / 干活 | 正在写入… / 正在忙… | 敲笔记本 |
| 读文件 / 检索 | 正在查阅… / 正在检索… | 举放大镜 |
| 理清思路 | 正在理清思路… | 头顶冒灯泡 |
| 整理上下文 | 正在整理上下文… | 喝咖啡 |
| 跑命令 | 正在执行… | 坐在电脑前 |
| 等你确认 | 在问你一件事 | 被点击（弹一下） |
| 一轮结束 | 搞定了！ | 蹦跳欢呼 |
| 出错 | 出错了… | 翻倒 |
| 会话开始 / 结束 | 我醒啦！ / 下次见～ | 挥手 / 睡觉 |
| 空闲 | （不显示云朵） | 呼吸待机 |

## 互动

- **拖动** → 挪位置（松手吸附）
- **单击 / 双击** → 摸头（「好舒服～」）
- **右键** → 菜单（摸头 / 藏起来 / 退出）
- **拖文件到它身上** → 弹格式菜单，就地转换
- **全屏看视频时自动收起**，退出全屏自己回来
- 藏起来后从**托盘图标右键 → 叫回小D** 找回

## 排错

| 现象 | 原因 / 处理 |
| --- | --- |
| 装完没反应 | hooks 不热加载，**重启 Studio 或新开会话** |
| 提示端口被占用 | 已经有一只小D 在跑（看右下角托盘 / 桌面） |
| 桌宠起不来 | 多半是没装 Pillow：`pip install Pillow` |
| 状态不更新 | 确认插件已启用：`reasonix plugin list` |
| 想直接测一次 | `echo '{"event":"PermissionRequest"}' \| python hooks/notify.py` |

## 包内文件

| 文件 | 作用 |
| --- | --- |
| `reasonix-plugin.json` | 插件清单（声明 7 个 hook） |
| `hooks/notify.py` | hook 转发器：读 stdin JSON → POST 给桌宠 |
| `bin/pet.py` | 桌宠本体：窗口、动画、云朵、互动、转换入口 |
| `bin/dino.py` | 像素形象定义（18 个动作，程序化生成） |
| `bin/convert.py` | 转换后端（Pillow / ffmpeg / Office COM） |
| `bin/dropfiles.py` | 拖放接收（纯 ctypes，无第三方依赖） |
| `bin/check.py` | 形象自检（连通性检查） |
